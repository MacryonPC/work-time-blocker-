# Work Time Blocker

#### Автоматический блокировщик отвлекающих сайтов в рабочее время через модификацию системного файла `hosts`.

# 🕒 Принцип работы

#### - **Рабочее время:** 09:00 – 16:20 (настраивается в коде)
#### - **В рабочее время:** сайты перенаправляются на `127.0.0.1` → доступ закрыт
#### - **Вне рабочего времени:** записи удаляются из `hosts` → доступ открыт
#### - **Проверка каждые 5 секунд** (настраивается через `time.sleep()`)
#### - Для работы со **системным** `hosts` требуется запуск от имени администратора:
  
  ## Windows: запустите командную строку "От имени администратора"
  ### python main.py

  ## Linux/macOS:
  ### sudo python3 main.py

# 🚀 Установка и запуск

### Откройте main.py и измените параметры:

## Список сайтов для блокировки

   ### 'www.youtube.com'
   ### добавьте свои домены сюда
### ]

### Скрипт работает локально, без передачи данных в сеть
### Все изменения ограничены файлом hosts
### Перед первым запуском рекомендуется создать резервную копию системного hosts:
### bash
### copy C:\Windows\System32\drivers\etc\hosts hosts.backup
